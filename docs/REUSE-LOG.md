## How to read this inventory

- **Copy:** upstream file body retained, with Labbonet attribution/change notice added. All included selectors are credited, even when currently unused.
- **Excerpt:** selected upstream rules, preserving their authorship; unused surrounding upstream features were not copied.
- **Structure adaptation:** upstream screen composition, vocabulary, classes or field grouping rebuilt in Labbonet. The UI design is credited to GobboNet; the API calls, state and security implementation are Labbonet work.
- **Behavior reference:** user-visible behavior checked against upstream, then independently implemented. This is design credit, not a claim that upstream source was copied.
- **Original integration:** Labbonet code connecting the adapted presentation to its backend. It does not make the underlying GobboNet visual design original to Labbonet.

[Machine-readable provenance](GOBBONET-PROVENANCE.json) records every source path, pinned-source SHA-256 and exact equal CSS line spans (one-based, inclusive; line endings normalized). Adapted HTML/JS is identified by component/function rather than falsely represented as a verbatim excerpt. Source hashes identify the upstream input, not a frozen hash of files still under development.

(schedule editor, enable/duplicate/run status), `js/13-dashboard.js` (home schedule

than replayed. No engine management or automatic model loading is added.
